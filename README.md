# Wedding Website Scraper

This project is a web scraper designed to extract all information from the tabs of a wedding website. The scraper navigates through the website's various sections (e.g., "About Us," "Events," "Gallery," "RSVP") and collects the data for further analysis or storage.

## Features

- Scrapes all tabs and sections of a wedding website.
- Extracts text, images, and other relevant data.
- Saves the data in a structured format (e.g., JSON, CSV).
- Handles dynamic content and JavaScript-rendered pages.
- Configurable for different wedding website templates.

## Prerequisites

Before running the scraper, ensure you have the following installed:

- Python 3.8 or higher
- [pip](https://pip.pypa.io/en/stable/) (Python package manager)
- Google Chrome and [ChromeDriver](https://chromedriver.chromium.org/) (for Selenium)
